# Benchmarks

This directory contains benchmark scripts for evaluating agent performance across different categories and configurations.

## Scripts

### benchmark_categories_any.py
Benchmark script for evaluating agent performance across product categories.

### run_baselines.py
Script for running baseline evaluations.

### tune_baselines.py
Script for tuning baseline configurations.

## Usage

Run benchmarks from the project root:
```bash
python benchmarks/benchmark_categories_any.py
```

## Notes

- These scripts are intended for performance benchmarking and baseline comparison
- Results are typically saved to the `experiments/` directory
- Refer to the evaluation framework documentation for structured evaluation runs
