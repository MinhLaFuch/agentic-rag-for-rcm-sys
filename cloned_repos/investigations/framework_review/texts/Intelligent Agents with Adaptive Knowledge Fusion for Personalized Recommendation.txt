Abstract
With powerful semantic understanding, planning, and decisionmaking capabilities, LLM-based agents have been applied to solve recommendation tasks. However, challenges remain in effectively evolving user preferences within agent modules and in leveraging external knowledge to improve recommendation accuracy. In this paper, we propose an innovative agent-based framework for personalized recommendation systems that integrates adaptive knowledge fusion to address these challenges. Our framework consists of two primary components: an intelligent agent and the fusion of external knowledge. The intelligent agent includes a memory module that simulates human-like retention of user-item interactions and a reasoning module that applies Chain-of-Thought (CoT) techniques to mimic human thought processes. Furthermore, we introduce two main strategies for knowledge fusion: (1) a preranking approach using external knowledge to reorder candidates and reduce bias, and (2) an ensemble method that combines multiple ranking signals for more accurate recommendations. Evaluations on three public datasets and the AgentSociety Challenge1 demonstrate the framework's effectiveness in enhancing recommendation quality and adaptability. The code is open-sourced2.

1 Introduction
Recommender systems (RSs) play a vital role in improving user experience and item dissemination, which have become an essential part of various domains, such as e-commerce, social media, and so on [5, 17]. Currently, the advancement of Large Language Models (LLMs) [3, 14, 16] has introduced LLM-based agents [13, 15, 23] capable of completing complex tasks. These agents' semantic understanding, planning, and decision-making skills unlock new potentials for context-aware personalized recommendations.
Researchers have started to utilize the capabilities of agents to solve recommendation tasks. Existing work [19, 24, 25] primarily focuses on employing agents for simulating user or item behaviors, providing insights into user preferences but falling short of integration into RSs. On the other hand, some studies [9, 20, 21] attempt to leverage the capabilities of agents to directly build a recommender, primarily building an agent with profile, planning, memory, and action modules. However, these methods might not align with realworld user preferences as LLMs suffer inherent bias such as input position bias and popularity bias without the calibration of external knowledge [11].
To overcome these limitations, we propose a novel agent framework that incorporates adaptive knowledge fusion for personalized recommendation. This framework is designed to fully leverage the potential of LLMs, enabling intelligent, context-aware recommendations through the dynamic integration of diverse information sources. The framework is composed of two primary modules: Agent and Knowledge Fusion. For the Agent, we design two key components: memory and reasoning. The memory module simulates human-like memory retention by storing relevant user-item interaction data and user-generated reviews. The reasoning module employs Chain-of-Thought (CoT) [22] techniques, mimicking human thought processes to analyze the information of the target user

and candidate items and generate personalized recommendations. Additionally, we propose two methods for Knowledge Fusion. The first method is a preranking phase that adjusts the initial candidate list based on external knowledge, such as item quality and popularity. This phase mitigates positional bias by ensuring that more relevant items are prioritized before the agent ranks them. The second method involves an ensemble process, where multiple ranking signals--such as quality rank, popularity rank, affinity rank, and agent rank--are weighted and combined to generate the final recommendation list. Our approach was evaluated on both public real-world datasets (Amazon [7], Yelp [2] and GoodReads[18]) and on the recommendation track of WWW'25 AgentSociety Challenge, a competition focused on advancing web experiences using LLM agents for personalized recommendations, and both showed superior performance.
In summary, our contributions are three-fold:
· We propose a novel agent-based framework that incorporates adaptive knowledge fusion for personalized recommendation. We design an intelligent agent with a memory and reasoning module, enabling the agent to effectively simulate human-like retention of user-item interactions and decision-making processes.
· We innovatively propose two knowledge fusion strategies for agent-based systems: one that uses external knowledge to prerank candidates, and another that combines multiple ranking signals through an ensemble method to improve accuracy.
· Our method demonstrates effectiveness on three public datasets and achieves a top-3 ranking in the AgentSociety Challenge at WWW'25, with a hit rate@5 of 0.6250.
2 Methodology
2.1 Overall Framework
To achieve more effective personalized recommendations, we present an agent-based framework that integrates adaptive knowledge fusion. Figure 1 illustrates the overall structure of our framework. Our framework consists of two main components: an intelligent agent and knowledge fusion. The agent includes a memory module (Sec. 2.2) to store key information from candidate items and user interactions, and a reasoning module (Sec.2.3) using a CoT technique. Knowledge fusion is performed in two ways: prerank the candidate list based on external knowledge (Sec.2.4), and ensemble the agent's ranked list with externally rank signals (Sec.2.5).
2.2 Intelligent Agent: Memory
The memory module serves as the core "brain" of the agent, simulating the human memory process. In actual interactions between a person and an item, individuals observe various features of the item, forming short-term memory. Afterward, only the most relevant information and impressions from the interaction are retained in long-term memory.
In our agent implementation, the memory module records key information from candidate items, user reviews, and historical interactions, while "forgetting" unimportant details. It stores data on interacted items, including their features and metadata, as well as user reviews that reveal sentiment and preferences. 2.3 Intelligent Agent: Reasoning
To enhance the LLM's reasoning and problem-solving abilities, we employ the Chain-of-Thought (CoT) [22] method to prompt the agent and guide it to perform a "step-by-step" reasoning process. By applying the CoT reasoning approach, the agent is encouraged to decompose the recommendation task into a series of sequential steps, simulating a human-like reasoning process that draws on both user history and item information. To ensure the LLM fully grasps the CoT prompt, an example of CoT reasoning can be provided to guide the agent through the process.
The prompt for CoT and an example of CoT is illustrated in the Figure 2, which is created with insights of domain expertise from SOTA LLMs (e.g., GPT-4o [10] and DeepSeek-R1 [6]), known for their strong CoT capabilities. In the CoT prompt, the agent is guided through a four-step process. First, the agent analyzes the user's historical interactions and reviews to infer user preferences for different item categories. Second, it reviews the attributes of the candidate items, ensuring a comprehensive understanding of their

2.4 Knowledge Fusion: Prerank
To incorporate external prior knowledge, we implement a preranking phase for items in the candidate list before deploying the agent for personalized recommendation. Existing studies [8] indicate that LLMs exhibit positional bias when performing recommendation tasks, where the initial ordering of candidate items may implicitly influence their final ranking decisions.
To mitigate this bias, we incorporate external prior knowledge to prerank the candidate items. Constrained by the competition rules, we primarily employ strategies based on the popularity of candidate items and their average ratings. This approach assumes that higher popularity and ratings are often indicative of broader appeal.

3 Experiments
3.1 Experimental Settings
Datasets. We evaluate our framework on three scenarios provided by the organizing committee: Amazon [7], Yelp [2], and GoodReads [18], each with 200 tasks consisting of 40% simulation data and 60% real data. Due to the lack of disclosed real data, we randomly sampled 120 user interactions per scenario, selecting users with at least one positive interaction ( 4 stars), and used their last interacted item based on chronological order as the ground truth. For Amazon and Goodreads, we randomly sampled 19 uninteracted items per user to form the candidate list. For Yelp, we ensured the sampled items shared at least one category with the ground truth item.

Challenge Requirements. The AgentSociety challenge employs Qwen-72b-instruct [1] as the base large language model for agents. The use of external models, the training of such models, or the integration of external tools are explicitly prohibited. It imposes a time limit of 120 minutes for a total of 600 tasks. Our framework achieves an average of 5 seconds per task (5 tasks in parallel) which is significantly lower than the prescribed time limits, demonstrating improved efficiency.
3.2 Performance of Agent: Memory
We analyze the performance of each module in detail. The primary function of the Agent: Memory module is to determine which information should be retained by the agent to inform future reasoning steps. This information is crucial for generating personalized recommendations and can be categorized into three key areas: the features of current candidate items (+Item Info), user historical reviews (+History Review), and the detailed information of previously interacted items (+History Item Info).
As shown in Table 2, all three types of information effectively enhance the agent's performance in the Amazon scenario. In the Yelp scenario, the agent particularly requires information about candidate items and users' historically interacted items. As for the Goodreads scenario, the reviews of users' historically interacted items are sufficient to characterize user preferences.
Observation 1. The information about candidate items and users' interaction history is crucial for the agent's predictive performance. However, different scenarios require emphasis on different aspects of the interaction history.
3.3 Performance of Agent: Reasoning
The Agent: Reasoning component introduces the CoT [22] mechanism to prompt the agent and guide it to perform a "step-by-step" reasoning process. We experimented with two different configurations:

· CoT: In this configuration, reasoning is performed using the CoT strategy, guided by the prompt shown in Figure 2.
· CoT w/ example: In this version, the CoT process is further enhanced by providing an example of CoT reasoning, as illustrated in Figure 2.
The experimental results demonstrate that the CoT with Example method performs better in the Amazon scenario, while vanilla CoT is more suitable for other scenarios.
Observation 2. Breaking down the recommendation task into a multi-step reasoning process through CoT proves to be effective in improving the agent's prediction accuracy.
3.4 Performance of Fusion: Prerank
The Fusion: PreRank module leverages external knowledge to provide initial rankings for candidate items before the agent memory and reasoning processes. Although our framework supports various strategies, we conducted experiments on two simple external knowledge fusion methods:
· Popularity: This method ranks items based on their overall popularity.
· Item Quality: Here, items are ranked based on quality metrics provided by item meta information (e.g., the average stars rated by users).
Overall, most prerank-based knowledge fusion methods lead to a decline in the agent's HR@1 performance, with the exception of the Item Quality prerank method in the Yelp scenario. The Item Quality prerank method shows some improvement in the agent's HR@3 and HR@5 performance in the Amazon scenario. However, the introduction of any prerank method results in decreased agent performance in the Goodreads scenario.
Observation 3. Integrating external knowledge through prerank can improve the model's HR@3 and HR@5 performance in some scenarios, though this typically comes at the cost of decreased HR@1 performance.

3.5 Performance of Fusion: Ensemble
For the Fusion: Ensemble module, we applied the Borda method [4] to integrate external knowledge and refine the rankings generated by the LLM. We experimented with varying numbers of LLM agent "voters" and two types of external ranking components: · Pop: This ranking is generated based on candidate items' overall
popularity. · Quality: This ranking is generated based on quality metrics pro-
vided by item information. Similar to the results of the Fusion: Prerank module, the introduction of external ranking leads to decreased agent performance in terms of HR@1. However, pop ranking shows some improvements in the agent's HR@3 and HR@5 performance in both Amazon and Yelp scenarios. In the Goodreads scenario, incorporating various external knowledge sources degrades agent performance, suggesting that user behavior is less correlated with these external knowledge sources in this scenario.
Observation 4. Incorporating external knowledge through ranking ensemble achieves better agent performance improvement in some scenarios compared to prerank, although HR@1 performance still experiences some degradation.

4 Conclusion
In this paper, we introduce a novel agent-based framework that incorporates adaptive knowledge fusion for personalized recommendation. The intelligent agent's memory and reasoning modules, alongside the two proposed knowledge fusion techniques, enable more personalized and accurate recommendations. Experiments on public datasets and performance in the AgentSociety Challenge validate the framework's robustness and adaptability.
We believe this work offers a fresh perspective on knowledge fusion for agent-based systems, emphasizing dynamic, contextaware integration of external knowledge to enhance personalized recommendation accuracy. Due to competition constraints, the integration of traditional recommendation algorithms was limited; future work could optimize knowledge fusion methods and explore their scalability in real-world applications.
