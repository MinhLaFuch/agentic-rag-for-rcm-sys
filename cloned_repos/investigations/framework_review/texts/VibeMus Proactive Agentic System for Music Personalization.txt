Abstract
Large language models (LLMs) enable diverse forms of AI-assisted creation, yet they often struggle to bridge the preference-articulation gap: users may provide incomplete or vague intentions or lack the vocabulary to specify what they want, yielding outputs misaligned with true preferences. To address this gap and facilitate music creation in a vibe-centric environment, we introduce VibeMus, a proactive agentic system built on open-source components. The system engages in multi-turn dialogue to progressively determine the music's emotion, genre, lyrics, and other aspects before generation. Simulated evaluations show that proactive clarification improves alignment with users' intended nuances. Our approach is training-free, leveraging an open-source music model, an opensource agentic framework, and publicly available LLM APIs. We release our code, showcase several demos, and provide additional details at https://github.com/tuteng0915/VibeMus.

1 Introduction
The rapid advancement of large language models (LLMs) has expanded creative human-AI collaboration, from article [19-21] and poetry [17] to music [6, 10, 15, 16] and visual art [22]. A persistent obstacle is the preference articulation gap: users struggle to express nuanced, experiential intents in an LLM-comprehensible way [3]. Limited vocabulary for abstract feelings, vague inspiration, and difficulty translating lived experience into actionable instructions often lead LLMs to proceed without sufficient clarification, yielding fabricated details and misalignment with the user's intent [8, 18].
Prior work on AI-assisted creative writing largely optimizes generation quality (e.g., style consistency, thematic relevance) under detailed, explicit prompts [10, 13, 17]. Personalization remains

challenging: lyric-generation work typically targets style transfer [2], melody consistency [11, 25], and emotion alignment [14] under static, fully specified prompts, often producing over-generic outputs. Meanwhile, proactive dialogue agents that ask clarifying questions before acting [7-9] have focused on structured, objective domains (planning, programming, embodied tasks) with clear goals and constraints [4, 24, 26]. In creative settings, tools often surface predefined options rather than eliciting open-ended preferences via agent-led dialogue--an underexplored direction.
To bridge this gap and enable AI-assisted music creation in a vibe-centric environment, we introduce VibeMus, a proactive agentic system for music personalization. The agent conducts multi-turn dialogue to surface latent preferences (e.g. emotional tone, narrative perspective, cultural references) before generation, and it supports natural-language, span-targeted editing. For evaluation, we leverage the ToT [1] dataset and simulate user-agent interactions to assess personalization fidelity via rubric-based scoring.
Our contributions are threefold: 1) We formalize proactive, openended preference elicitation for creative music generation as an iterative, dialog-driven process with a lightweight stopping rule and question-selection heuristic; 2) We provide a training-free, reproducible evaluation protocol on ToT-derived requests, including simulated users and rubric prompts for LLM-based assessment; 3) We empirically show that proactive dialog improves alignment over one-shot generation given the same initial prompt and approaches an oracle that receives the full requirement.
2 System Design
The overall system is a proactive agentic system, as shown in Figure 1. At the core of the system are two agents: 1) an interface chatbot agent, which elicits user intentions into lyrics, music tags, and atomic edits, implemented as a prompting strategy based on the Qwen Agent [5]; 2) a music generation agent, built on the opensource ACE-Step [12] for lyrics-to-music synthesis. We implement our system as a website, where the front end uses a Gradio interface for user-system interaction, while calling Qwen LLM via web API and running ACE-Step model at the backend. Interface Chatbot Agent follows a clarify-then-generate workflow. (1) Proactive Clarification: After receiving the initial instruction, the agent identifies unresolved aspects necessary for song generation, such as emotional tone, narrative perspective, cultural references, or specific words and phrases in the target lyrics. The agent then formulates targeted follow-up questions based on the

missing aspects and asks the user for clarification. (2) Creative Generation & Editing: When the agent gathers enough information, it generates a draft of the lyrics and tags for the user and asks for confirmation. The user may request for further polishing. Once the user confirms, the agent activates song generation using the ACEStep model. After that, if the user wants the generated result to be further revised, the agent can interpret granular editing requests and translate them into tool calls, including extending, clipping, repainting, or editing the song at specific lines or time segments.

3 Demonstration and Evaluation
To evaluate our system, we use a subset of the dataset  [1], a dataset of tip-of-the-tongue song finding requests, which covers different aspects of the required music. To make it suitable for our task, we transform the song finding requests into song generating requests via LLM, which aims to simulate a real user prompt. Each request is defined as a set of atomic elements:  = {1, 2, . . . }, and for every user message, it covers some newly mentioned items    ( = 0 represents the initial request). Each element is categorized in one of the following 5 aspects: "Genre", "Time Period / Recency", "Story/Lyric Description", "Vocals", "Composition", which are picked from the original dataset for being related to music generation, and are able to cover different aspects of information required in song generation. We feed the song requests to an LLM simulating user behavior and make it communicate with the models. Along with our proposed strategy, we conduct the experiment on an agent without proactive mechanism. In addition to the user simulator, as comparison, we also test the system with the input of full intentions. We then assess each set of generated lyrics and tags with a judge LLM 1, which scores each generated lyrics and tags 0  10 points

4 Conclusion
We present a proactive agentic system for music personalization that interacts with the user to surface latent intentions, clarify under-specified instructions, and then generate lyrics and song tags as inputs to downstream music-generation models; the agent also supports natural-language, span-targeted editing. For future work, we will add human evaluation, extend to other creative modalities. In addition, a limitation concerns ethical and safety considerations: creative generation entails risks of style imitation (potential appropriation), cultural insensitivity, and inappropriate lyrical content. In this prototype, we rely on provider-side LLM safety filters for refusal, redaction, and toxicity moderation.
